# OpenDiff leftovers

Docs inherited from the upstream OpenDiff project (mostly Chinese): requirements, Beyond Compare parity audits, the old release checklist (macOS/Linux builds, no longer used), and the original README with its translations and screenshots. They're kept for reference only. DeepServer's install and release docs are `docs/install.md` and `docs/releasing.md`.

Three vitest suites still check the performance budget, security audit and accessibility checklists here (`src/app/*Checklist.test.ts`, `performanceBudget.test.ts`).
